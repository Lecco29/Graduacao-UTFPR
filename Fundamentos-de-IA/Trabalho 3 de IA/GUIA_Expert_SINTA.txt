POR QUE TRANSCREVER (e nao "abrir" um arquivo pronto)
-----------------------------------------------------
O Expert SINTA salva a base de conhecimento em formato proprietario .bcm
(binario, serializado pelo Delphi). Ele NAO possui importacao por arquivo de
texto. Portanto, as bases foram entregues como roteiro de texto
(Sistema1_Celebridades.txt e Sistema2_Filmes.txt) e devem ser digitadas dentro
do shell e salvas como .bcm. Este guia mostra como fazer isso e como apresentar
o sistema funcionando.


0. INSTALACAO / EXECUCAO DO SHELL
---------------------------------
O Expert SINTA e' um programa Windows de 32 bits (decada de 1990).
- Pasta do instalador: sinta\SINTA\sinta32.zip  (descompacte e execute o setup)
- Em Windows 10/11 modernos, rode em modo de compatibilidade (Windows XP) ou,
  se preferir, dentro de uma maquina virtual Windows.
- No Linux, funciona muito bem via Wine:
      unzip sinta32.zip -d sinta32 && wine sinta32/SETUP.EXE
  (ou rode diretamente o EXPSINTA.EXE instalado, com 'wine EXPSINTA.EXE').
- Manual oficial: "Manual - Expert SINTA.pdf" (raiz do trabalho).


1. CRIAR A BASE
---------------
Menu  Arquivo > Novo.  Em seguida preencha "Sistema > Informacoes" com Nome,
Autores e Resumo (textos prontos na secao 1 de cada arquivo .txt).


2. CADASTRAR AS VARIAVEIS (aba "Variaveis")
-------------------------------------------
Para cada variavel da secao 2 do .txt:
  a) Clique em "Nova", digite o nome EXATAMENTE como no arquivo
     (ex.: tipo_celebridade, genero_obra, filme...).
  b) Escolha o TIPO:
       - univalorada  -> aceita 1 valor (ex.: cor_cabelo, duracao).
       - multivalorada-> aceita varios valores marcados (genero_obra,
         caracteristica, genero_filme, estilo, e os OBJETIVOS celebridade/filme).
       - numerica     -> nao usamos neste trabalho.
  c) Cadastre os VALORES POSSIVEIS listados abaixo do nome da variavel.
     ATENCAO: o texto do valor tem que ser IDENTICO em todas as regras
     (inclusive parenteses e acentos que voce decidir usar). Mantenha o padrao.

Dica: cadastre PRIMEIRO a variavel-objetivo (celebridade / filme) e todos os
seus valores (os nomes da secao 3), pois as regras vao se referir a eles.


3. DEFINIR O OBJETIVO (aba "Objetivos")
---------------------------------------
Adicione a variavel "celebridade" (Sistema 1) ou "filme" (Sistema 2) como
objetivo. E' esse valor que o motor de inferencia vai tentar descobrir.


4. CADASTRAR AS PERGUNTAS
-------------------------
Em cada variavel ha um campo de "Pergunta" (texto exibido ao usuario durante a
consulta). Use os textos da secao 4 do arquivo. Variaveis que NAO sao objetivo
precisam de pergunta; o objetivo nao e' perguntado (e' inferido).


5. CADASTRAR AS REGRAS (aba "Regras")
-------------------------------------
Para cada regra da secao 5:
  a) Clique em "Nova regra".
  b) Monte as premissas do "SE": escolha a variavel, o operador "=" e o valor.
     Use "E" entre as premissas (este trabalho usa apenas conjuncao).
  c) Monte a conclusao do "ENTAO": variavel-objetivo = valor, e informe o
     FATOR DE CONFIANCA (CNF) indicado em cada regra (ex.: 95%).
  d) Repita para todas as regras (35 no Sistema 1, 56 no Sistema 2).

Observacao sobre premissas repetidas (ex.: "genero_obra = acao" E
"genero_obra = comedia"): isso e' valido porque genero_obra e' MULTIVALORADA;
significa "a obra e' de acao E tambem de comedia".


6. CONFIGURACOES DA BASE (Opcoes)
---------------------------------
- Operador de maior precedencia: conjuncao.
- Fator de confianca minimo para aceitar regra: 0 (assim toda recomendacao com
  CNF > 0 aparece na lista de resultados, ordenada por confianca).
- Pode deixar as formulas de confianca no padrao (conjuncao = minimo,
  disjuncao = maximo, conclusao = CNF da regra * confianca das premissas).


7. SALVAR
---------
Arquivo > Salvar como ->  CelebreMatch.bcm  (Sistema 1)
                          CineGuia.bcm       (Sistema 2)


8. EXECUTAR A CONSULTA (apresentacao)
-------------------------------------
Menu  Consulta > Iniciar  (ou o botao de "play").
O SINTA vai perguntar as variaveis e, ao final, mostrar a lista de celebridades
/ filmes ordenada pelo fator de confianca. Recursos para mostrar na apresentacao:
  - "Por que?"  -> o sistema explica por que esta perguntando aquilo.
  - "Como?"     -> mostra como chegou a determinada conclusao (encadeamento).
  - Historico   -> rastreio das regras disparadas.


9. ROTEIROS DE TESTE SUGERIDOS (para a apresentacao em sala)
------------------------------------------------------------
Sistema 1 - CelebreMatch:
  Teste A) ator ou atriz / masculino / norte-americana / careca ou sem cabelo /
           acao / muito musculoso(a)  -> esperado: Dwayne Johnson (The Rock).
  Teste B) cantor ou cantora / masculino / britanica / preto / rock /
           barba ou bigode / classica -> esperado: Freddie Mercury.
  Teste C) atleta / masculino / brasileira / preto / futebol / classica
           -> esperado: Pele.

Sistema 2 - CineGuia:
  Teste A) crime ou policial + drama / longa / classico / Hollywood / adulto /
           premiado=sim -> esperado: O Poderoso Chefao.
  Teste B) crime ou policial + drama / longa / 1990-2009 / nacional / adulto /
           historia real / premiado=sim -> esperado: Cidade de Deus.
  Teste C) serie + crime + drama / episodica / recente / Hollywood / adulto /
           premiado=sim -> esperado: Breaking Bad.
  Teste D) (consulta por ator) ator_principal = Leonardo DiCaprio
           -> esperado: Titanic, A Origem e Django Livre (ranqueados por CNF).


10. OBSERVACOES DE MODELAGEM (bom citar na apresentacao)
--------------------------------------------------------
- O objetivo e' MULTIVALORADO de proposito: assim o sistema funciona como um
  RECOMENDADOR (lista varias opcoes ranqueadas), e nao um classificador unico.
- Quanto MAIS caracteristicas o usuario informa, mais especifica a resposta;
  com poucas respostas coincidindo, varias celebridades/filmes aparecem com
  CNFs proximos -> mostra o comportamento de "raciocinio sob incerteza".
- A base foi montada por pesquisa de atributos reais (nacionalidade, epoca de
  auge, genero de obra, premiacoes) de cada celebridade/filme.
